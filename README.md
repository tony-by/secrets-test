# Secrets Test Repository

Этот репозиторий создан для тестирования сканеров безопасности на предмет обнаружения различных типов секретов.

## Типы секретов в репозитории

### API ключи и токены

- OpenAI API ключи
- GitHub токены
- AWS ключи доступа
- Stripe секретные ключи
- JWT секреты
- OAuth токены

### Пароли баз данных

- PostgreSQL пароли
- MongoDB пароли
- Redis пароли
- MySQL пароли

### Облачные сервисы

- AWS credentials
- Azure credentials
- Google Cloud credentials
- Kubernetes токены

### CI/CD секреты

- GitHub Actions secrets
- GitLab CI переменные
- Docker registry пароли

## Форматы файлов

- `.env` файлы
- JSON конфигурации
- YAML конфигурации
- XML конфигурации
- Properties файлы
- Docker файлы
- Kubernetes манифесты
- Terraform переменные

## Предупреждение

⚠️ **ВНИМАНИЕ**: Этот репозиторий содержит тестовые секреты и НЕ должен использоваться в продакшене!

Все секреты в этом репозитории являются тестовыми и не представляют реальной угрозы безопасности.
